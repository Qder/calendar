# 国产 Android「提醒收不到？」引导

> 真机项默认**未验证**。以下为常见 OEM 设置路径摘要；名称因厂商/系统版本而异。

## 必做

1. **通知权限**：设置 → 应用 → 日历（Calendar / com.qder.calendar）→ 通知 → 允许全部。
2. **精确闹钟 / 闹钟和提醒**：允许（Android 12+ 常见；应用内也可点「尝试打开系统设置」跳转）。
3. **自启动**：允许应用自启动（小米/红米、华为/荣耀、OPPO/一加、vivo/iQOO、三星等「自启动管理」）。
4. **后台耗电 / 电池优化**：设为「不优化」或「无限制」，避免划掉任务后杀后台。
5. **锁屏通知**：允许在锁屏显示。

## 建议自测

见 [`real-device-test.md`](./real-device-test.md)：前台 / 后台 / 划掉 / 锁屏 / 重启。

## 应用内入口

设置 → **提醒收不到？** →「尝试打开系统设置」或「查看引导摘要」。
